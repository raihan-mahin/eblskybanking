# EBL SkyBank Mobile


A mobile-first banking experience prototype by **Raihan Mahin**. This project explores how everyday banking, money requests, savings and rewards can fit into a clear, interactive mobile interface.


**[Open the live prototype](https://eblskybanking.lovable.app)**


## Project purpose


I created this prototype to turn a banking product concept into a clickable experience. It brings together familiar banking journeys and proposed services so the navigation, screen design and customer experience can be explored.


## Featured journeys


- Mobile-style login and simulated authentication.
- Quick Banking and service discovery.
- Transfer and payment journeys using demo data.
- Request Money: select an EBL demo user, enter an amount and note, review and send a request, and track its status.
- Incoming money requests with Pay Now and Decline actions.
- Savings, Group DPS and rewards concepts.
- Promotional banners linking to entertainment payment and offer screens.


## My contribution


I provided the product brief, visual references and feature requirements, then directed refinements to the user journey and interface.


## Demo scope


This is an independent portfolio prototype inspired by EBL Skybanking, not an official banking application. It uses fictional local data and simulated banking flows. It does not connect to real banking systems or process real payments. Use demo information when exploring it.
